# handoffs/

One short note per conversation that ended, so the next conversation starts exactly where
this one stopped. Written by the `handoff` skill; read first by every new session.

- Name: `YYYY-MM-DD-<topic>.md` (add `-2`, `-3` for several on one day).
- At most 60 lines: where we are, what was done (with file paths), decisions and why,
  the exact next action, questions waiting for the owner, traps to avoid.
- Notes are summaries, never transcripts. No secrets, no private client data.
- The always-current summary is `docs/wiki/state.md`; handoffs are the trail behind it.
  Old notes are never edited.
